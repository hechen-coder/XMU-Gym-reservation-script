========================================================================
             厦大体育馆自动预约工具 (XMU Gym Booking) - 使用说明
========================================================================

欢迎使用厦大体育馆自动预约工具！本程序已内置完整运行环境与离线识别引擎，
【无需安装 Python】，【无需配置命令行】，解压后双击即可直接使用！

------------------------------------------------------------------------
一、 两种打开与运行方式
------------------------------------------------------------------------

【方式 1：双击运行 XMU_Gym_Booking.exe (最推荐)】
1. 直接双击运行【XMU_Gym_Booking.exe】；
2. 终端会自动弹出人性化功能导航菜单：
   - 输入 1 并回车：启动 Web 预约控制台并自动打开浏览器 http://localhost:8080 (默认)；
   - 输入 2 并回车：启动早 7 点准点抢次日票任务 (睡前挂机秒杀神器)；
   - 输入 3 并回车：启动微信免抓包凭证嗅探 (备用方案)；
   - 输入 4 并回车：在终端中以表格形式查询场馆实时余票。

【方式 2：使用桌面批处理快捷脚本 (一键直达)】
- 双击【启动网页版.bat】：一键直接启动可视化 Web 预约平台；
- 双击【启动早7点定时抢票.bat】：一键直接进入睡前挂机秒杀状态；
- 双击【一键登录_自动截取凭证.bat】：直接唤醒嗅探截取登录凭据。

------------------------------------------------------------------------
二、 核心操作流程（扫码登录 ➔ 查看余票 ➔ 一键预约/早7点挂机）
------------------------------------------------------------------------

【第 1 步：打开 Web 控制台】
- 启动程序后，浏览器会自动打开网页：http://localhost:8080；
- 页面将直观展示当天与次日所有时段的名额进度条。

【第 2 步：登录系统 (首选：手机企业微信扫码)】
★ 方案 A（最推荐 · 免装电脑微信 · 3秒直达）：
  1. 点击网页顶部的【📱 扫码登录】按钮；
  2. 页面将直接显示官方统一身份认证二维码；
  3. 打开手机端【企业微信 APP】，使用右上角【+】➔【扫一扫】扫描二维码；
  4. 手机上点击【确认登录】，系统将在 1 秒内自动完成授权并跳转回预约大厅！

★ 方案 B（备用兜底 · 微信嗅探）：
  - 若无法使用扫码，可在网页点击【🔑 微信嗅探】；
  - 确保电脑端微信已登录，打开【厦大体育】小程序点击【场馆预约】即可自动捕获凭证。

【第 3 步：实时查看余票与一键预约】
- 登录成功后，网页顶部会变为绿色的【● 登录态有效】；
- 看到有名额的时段，直接点击右侧绿色的【⚡ 立刻预约】；
- 内置本地离线 OCR 引擎在 0.1 秒内自动识别验证码并秒速锁定场地！

【第 4 步：早 7 点全自动秒杀抢票 (定时挂机)】
- 厦大系统每天早上 07:00:00 准点开放次日名额；
- 睡前双击【启动早7点定时抢票.bat】（或运行 exe 菜单输入 2）；
- 次日早 06:55 程序自动唤醒预检并无感自愈登录态；
- 07:00 准点毫秒级并发抢票！若首选时段已满，算法会自动就近抢相邻时段，确保不空手而归！

------------------------------------------------------------------------
三、 ⚠️ 关键注意事项：挂机过夜电脑绝对不能休眠！
------------------------------------------------------------------------
- 运行早 7 点定时抢票挂机过夜时，电脑绝对不能进入休眠或睡眠状态！
- 电脑休眠会导致 Wi-Fi 断开、后台进程挂起，从而错过 07:00 抢票时机。
- 正确设置防休眠方法：
  1. 连接电源线：笔记本过夜务必插上电源适配器；
  2. 关闭睡眠：打开 Windows「设置」➔「系统」➔「电源和电池」➔「屏幕和睡眠」，将「接通电源时，经过以下时间后使设备进入睡眠状态」设置为【从不】；
  3. 防合盖休眠：若需要合上笔记本屏幕，请在控制面板电源选项中将「关闭盖子时所做的操作」设置为【不采取任何操作】；
  4. 支持安全锁屏：挂机期间完全可以锁屏！直接按快捷键【Win + L】锁屏即可，后台程序与抢票网络完全不受影响。

------------------------------------------------------------------------
四、 📱 配置免费微信抢票成功提醒 (可选，1分钟搞定)
------------------------------------------------------------------------
1. 打开手机微信，搜索关注公众号【PushPlus (推送加)】并复制你的【Token】；
2. 用记事本打开 config/config.yaml 文件，填入你的 token：
   notify:
     enabled: true
     channel: "pushplus"
     pushplus_token: "你的PushPlus_Token填在这里"
3. 保存文件即可。次日早 7 点抢票成功后，手机微信将第一时间秒弹卡片通知！

------------------------------------------------------------------------
五、 常见问题与排坑
------------------------------------------------------------------------
1. Q: 提示网络连接失败或接口超时？
   A: 厦大体育接口位于校内网。如果在校外、宿舍非校园网或使用手机热点，请务必提前连接【厦大 WebVPN 或 EasyConnect 校园 VPN】。
2. Q: 提示登录失效？
   A: 在网页端点击【📱 扫码登录】重新扫码，或点击【⚡ HTTP 自动续登】即可秒级恢复。
3. Q: 预约成功后在哪里查看？
   A: 可在手机【厦大体育】小程序的「我的预约」或本项目 Web 网页端中直接查看确认。
