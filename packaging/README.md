## 本地快速打包快速参考

- **鼠标双击打包**：直接双击当前目录下的 一键构建发布包.bat；
- **命令行打包**：在项目根目录运行 python packaging/build_release.py；
- **产物输出**：构建完成后产物存放于 dist/ 目录下（绿色便携压缩包与 Windows 安装程序）。
