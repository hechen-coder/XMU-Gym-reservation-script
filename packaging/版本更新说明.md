## 🌟 厦大体育馆自动预约工具 (XMU Gym Booking) v1.1.2 修复发布

欢迎使用 **厦大体育馆自动预约工具 v1.1.2**！本次版本为重要稳定性与体验加固修复版，主要修复了弹窗按钮卡死问题，并引入了 Windows 单实例互斥机制以杜绝多开冲突。

---

### 🛠️ 核心修复与优化清单

#### 1. ⚡ 修复预约成功弹窗“我知道了”按钮无法点击生效的卡死问题
- **根因排查**：在立刻预约确认流程中，原前端代码误将弹窗确认按钮当成表格预约按钮添加了 `disabled=true` 属性；当秒杀成功弹出“🎉 恭喜您预约成功！”提示框时，按钮文字变更为“我知道了”，但未清除 `disabled` 状态，导致 Chromium 浏览器根据标准拦截了用户的所有鼠标点击事件，弹窗无法关闭且无法刷新页面。
- **修复方案**：
  - 预约按钮采用 `this` 传参精准锁定原生表格行按钮，杜绝弹窗与表格按钮状态相互污染；
  - 弹窗系统（`customAlert` / `customConfirm` / `customPrompt`）每次呼出时强制重置 `disabled = false`，保证按钮绝对可交互；
  - 全面加固全局弹窗交互：支持按键盘 `Esc` 键退出、点击半透明遮罩背景自动关闭、按 `Enter` 键快速确认/提交；
  - 优化弹窗退出时的 Promise 垃圾回收与事件监听解绑，彻底杜绝悬挂卡死。

#### 2. 🛡️ 客户端防双击多开与单实例互斥唤醒（避免抢票冲突）
- **根因排查**：打包后的 exe 在被连续双击或重复点击时，会同时拉起两个独立的桌面窗口进程，不仅导致本地 8080 端口冲突，还会并发读写同一配置尝试预约两人造成逻辑混乱。
- **修复方案**：
  - 引入 Windows 原生命名互斥体（`Global\XMU_Gym_Booking_Desktop_SingleInstance_Mutex`）实现进程级单实例保护；
  - 当检测到程序已在运行时，二次启动进程自动通过 Win32 API 寻找原窗口并将其恢复置顶、切换至屏幕最前台；
  - 弹出系统级置顶提示框：**“【厦大体育馆自动预约工具】已在运行中（已打开）！已为您自动切换至已打开的窗口，请勿重复运行多个实例。”**；
  - 二次启动进程自动调用 `sys.exit(0)` 干净退出，彻底阻断多开；
  - Web 服务端增加对端口 8080 占用的优雅捕获与告警日志，防止后台线程崩溃。
