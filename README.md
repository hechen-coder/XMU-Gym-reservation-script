# 厦大体育馆自动预约工具 (XMU Gym Booking) 🏋️‍♂️

> 面向厦门大学师生的体育馆（翔安校区 / 思明校区健身房等）极速预约与早 7 点准点抢票工具。  
> **无需复杂抓包**，支持**网页直观预约**与**早 7 点全自动挂机秒抢**，零编程基础也能轻松上手！

---

## ✨ 核心功能亮点

- 🌐 **网页图形界面**：浏览器直观查看全天余票进度条，点选时段一键预约。
- ⏰ **早 7 点自动抢票**：睡前挂机，次日早 06:55 自动自检刷新凭据，07:00 准点毫秒级秒抢次日名额。
- 🔑 **微信免抓包登录**：自动调起电脑微信截取凭证并长期保活，无需手动抓包看 Cookie。
- 🎯 **就近时段智能降级**：若首选黄金时段被抢空，算法自动替你抢最临近的可用时段，绝不空手而归。
- 🔄 **退票捡漏秒杀**：热门时段已约满？开启捡漏模式持续监控，一旦有人退票出空位立即秒杀。
- 📱 **微信推送提醒**：抢票成功后手机微信秒弹卡片通知，场地、日期、时段一目了然。

## 📦 获取与使用（两种方式任选）

### 🌟 方式一：直接下载电脑安装包 / 免安装绿色版（零门槛，无需安装 Python！）

普通用户推荐直接下载打包好的独立安装包，无需配置 Python 环境与命令行：
1. 前往本项目的 **Releases 发布页面** 下载最新版：
   - 📦 **免安装绿色便携版**：`XMU_Gym_Booking_v1.0.0_Portable_Windows_x64.zip`（下载解压即可直接双击运行）；
   - 💿 **Windows 安装向导程序**：`XMU_Gym_Booking_Setup_v1.0.0.exe`（如同专业软件，自动创建桌面与开始菜单快捷方式）。
2. 解压或安装后，**直接双击运行主程序 `XMU_Gym_Booking.exe`**，浏览器将自动唤醒打开网页预约平台！
3. **本地一键打包**：如果你克隆了源码，只需双击运行 `packaging/一键构建发布包.bat`，即可秒级生成专属于你的发布包。

---

### 💻 方式二：Python 源码运行（适合开发者）

#### 第 1 步：安装运行环境

1. 下载并安装 [Python 3.8 或更高版本](https://www.python.org/downloads/)。
   
   > ⚠️ **关键注意**：安装时**务必勾选**最下方的 `Add Python to PATH`（将 Python 添加到环境变量）！
2. 打开电脑的命令行终端（命令提示符 CMD 或 PowerShell），进入本项目文件夹，运行命令安装依赖：
   ```bash
   pip install -r requirements.txt
   pip install ddddocr
   ```
   *(如遇下载慢，可使用国内清华源：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt`)*

---

### 第 2 步：检查与修改配置 (只需改 1 处！)

项目配置文件为 `config/config.yaml`（**首次运行时系统会自动根据模板生成，无需手动创建**）。

用记事本或任意文本编辑器打开 `config/config.yaml`，你通常**只需要确认/修改你想约的时段**：

```yaml
target:
  # 改成你想约的时段即可 (例如 18:00-19:30、19:30-21:00)
  preferred_time: "19:30-21:00"

  # 1 为预约明天(早7点抢次日票，默认)，0 为预约今天
  target_date_offset: 1
```

> 💡 **登录凭证（auth）完全不需要手动填写**！系统运行时会自动帮你从微信截取并保存。

---

### 第 3 步：开始使用 (两种推荐方式任选其一)

#### 🌟 方式 A：网页可视化预约（最直观、推荐随手约）
- **Windows 用户**：直接**双击运行 `启动网页版.bat`**；
- 或在终端输入：
  ```bash
  python main.py web
  ```
- 浏览器会自动打开 `http://localhost:8080`：
  - 页面清晰展示当天及次日所有时段的已约/总名额；
  - 找到想约的时段，直接点击 **【⚡ 立刻预约】** 即可秒级下单；
  - 凭证过期时，点击顶部 **【⚡ HTTP 自动续登】** 或 **【🔑 微信自动登录】** 即可一键恢复。

#### ⏰ 方式 B：早 7 点准点抢次日票（适合提前一晚挂机）
- 厦大体育系统每天早 07:00 准点开放次日预约名额。
- **Windows 用户**：晚上睡觉前直接**双击运行 `启动早7点定时抢票.bat`**；
- 或在终端输入：
  ```bash
  python main.py schedule
  ```
- 程序将进入倒计时挂机状态：
  - **早 06:55**：自动唤醒自检，若登录过期自动无感自愈刷新凭据；
  - **早 07:00:00**：准点毫秒级发起抢票；
  - **首选满额自动就近抢**：若 19:30-21:00 满额，自动降级抢 18:00-19:30；
  - **成功后即时通知**：抢票结果自动发送到你的手机微信。

## 🔑 如何登录？（免手动抓包）

本系统提供完全自动化的微信小程序凭证捕获机制：

1. 确保电脑上的 **Windows 微信已登录**；
2. **双击运行 `一键登录_自动截取凭证.bat`**（或终端运行 `python main.py harvest`）；
3. 程序会自动临时启动本地安全嗅探、调起微信小程序截取凭证，并自动写入 `config/config.yaml`；
4. 提示 `✅ [成功]` 后，登录态即可维持长期有效（系统后台自带心跳保活与失效自动续期）。

*(备用方式：如果你熟悉浏览器 F12 抓包，也可手动将抓到的 `PHPSESSID` 填入 `config/config.yaml` 的 `phpsessid: "xxx"` 中。)*

## 📱 接收微信抢票成功提醒 (可选)

想在早 7 点躺在床上就能知道抢票结果？只需 1 分钟配置微信推送：

1. 微信扫码登录免费的 [PushPlus 推送加官网](https://www.pushplus.plus/)；
2. 在网站右上角复制你的 **Token**（一串英文字符）；
3. 打开 `config/config.yaml`，填入下方即可开启微信通知：
   ```yaml
   notify:
     pushplus_token: "你的PushPlus_Token"
   ```
4. 抢票成功后，手机微信将第一时间收到包含场馆、日期、时段的卡片通知！

## ❓ 常见问题与避坑指南 (FAQ)

### Q1: 提示网络请求失败、连接超时或无法连接到服务器？
> **核心原因**：厦大体育系统 (`xdty.xmu.edu.cn`) 属于校内网络资源。  
> - 若使用**校园网 (Wi-Fi/有线)**：可直接正常使用；  
> - 若在**校外或使用手机移动热点**：电脑必须开启 **厦大 WebVPN 或 EasyConnect 校园 VPN**！

### Q2: 提示验证码拉取/识别失败？
> 请确认是否安装了离线高精度验证码库：
> ```bash
> pip install ddddocr
> ```

### Q3: 运行早 7 点抢票时，电脑可以合上盖子或休眠吗？
> **不可以**！电脑休眠或睡眠会中断网络与程序运行。  
>
> - **可以锁屏**（按键盘 `Win + L`），锁屏不影响抢票；  
> - 请确保在 Windows「电源和电池」设置中，将「屏幕关闭后进入睡眠」改为 **“从不”**。
